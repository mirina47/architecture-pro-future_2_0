# Описание агрегатов системы «Будущее 2.0»

## Patient Context

### Patient
**Границы агрегата:**
- Персональные данные пациента
- Контактная информация
- Статус пациента

**Ключ:** patientId 

**Инварианты:**
- Идентификатор пациента уникален
- Медицинские данные не передаются в аналитическую платформу напрямую
- Пациент не удаляется, а переводится в неактивный статус

## Clinical Context
### Appointment

**Границы агрегата:**
- Запись на прием
- Дата и время приема
- Назначенные исследования
- Статус приема

**Ключ:** appointmentId 

**Инварианты:**
- Прием всегда связан с пациентом
- Услуга должна быть оказана в рамках приема
- Для завершенного приема фиксируется результат оказанной услуги

### Medical Study

**Границы агрегата:**
- Исследование
- Результаты исследования
- Статус обработки

**Ключ:** studyId 

**Инварианты:**
- Исследование относится к одному пациенту
- Результат нельзя изменить после подтверждения
- Каждое исследование имеет уникальный идентификатор

## Finance Context

### Account

**Границы агрегата:**
- Счет клиента
- Баланс
- История операций

**Ключ:** accountId 

**Инварианты:**
- Баланс рассчитывается на основе операций
- Счет принадлежит одному клиенту
- Операция не может быть выполнена дважды

### Payment

**Границы агрегата:**
- Платеж
- Информация о списании средств

**Ключ:** paymentId 

**Инварианты:**
- Cумма платежа должна быть положительной
- Платёж не может быть проведён повторно

### Loan

**Границы агрегата:**
- Кредитный договор
- Сумма кредита
- График платежей

**Ключ:** loanId 

**Инварианты:**
- Кредит связан с клиентом
- Сумма кредита должна быть больше нуля
- Закрытый кредит не может быть изменен

## AI Diagnostics Context

### Inference Request

**Границы агрегата:**
- Запрос на анализ
- Исходные данные исследования
- Результат работы модели

**Ключ:** inferenceId 

**Инварианты:**
- Запрос связан с исследованием
- Используется конкретная версия модели
- Результат сохраняется после завершения анализа

## Data Platform Context

### Data Product

**Границы агрегата:**
- Дата-продукт
- Набор метрик
- Правила доступа

**Ключ:** dataProductId 

**Инварианты:**
- Дата-продукт имеет владельца
- Медицинские карты и результаты исследований не публикуются в аналитические витрины
- Доступ определяется ролью пользователя

### Report

**Границы агрегата:**
- Отчет
- Набор показателей
- Параметры фильтрации

**Ключ:** reportId 

**Инварианты:**
- Отчет строится только на доступных дата-продуктах
- Пользователь видит данные в пределах своих прав доступа
