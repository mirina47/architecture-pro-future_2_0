# TCO-анализ трансформации: текущая vs целевая архитектура (3 года)

> Значения являются условными!

## Исходные допущения
- Текущая архитектура построена на базе Legacy DWH (SQL Server 2008), Apache Camel и PowerBuilder
- Целевая архитектура использует Kafka, Kubernetes, PostgreSQL, Object Storage и Data Mesh-подход
- Для оценки используется сравнительная модель TCO на горизонте трёх лет
- Значения являются оценочными и используются для обоснования архитектурных решений

**Ожидаемая экономия за 3 года:*- около **21 000 тыс. руб. (~25%)**.

## Бизнес-эффект
- Сокращение времени подготовки отчётов и аналитических витрин.
- Переход от batch-обработки к near-real-time аналитике.
- Упрощение подключения новых доменов и внешних партнёров.
- Снижение зависимости от Legacy DWH и Apache Camel.
- Повышение производительности аналитиков за счёт Self-Service подхода.

## Вывод
Несмотря на дополнительные затраты на миграцию в первый год, целевая архитектура обеспечивает снижение совокупной стоимости владения за счёт сокращения расходов на лицензии, сопровождение и подготовку данных. Новая платформа лучше поддерживает масштабирование бизнеса и развитие новых направлений.
